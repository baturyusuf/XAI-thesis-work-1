# Independence policy

2026-10-22. Independence is not a branch name.

| Level | This round | Not established |
|---|---|---|
| A reproduction | 56 original A3 tests and tiny artifact matched on same Windows/Python | Cross-platform, native methods, real data |
| B independent numeric | 15 standalone reference tests plus 8 new differential checks | All inputs, formal numerical verification |
| C scientific | Estimand/theorem/protocol critique | Method adequacy, novelty, true law, factual IID or secure custody |

The three test_h1/h2/ltt_reference.py files import no benchmark code. test_pinned_implementation.py imports unchanged pinned code only for actual values; expected answers use truth-table sums, permutation enumeration, exact binomial and 70-digit Decimal arithmetic. Original A3 tests remain under original source_copy paths and are NOT independent tests. Shared mathematical fixtures are disclosed; no test function was renamed/copied as independent evidence.

Agreement cannot exclude a shared specification error. Frozen metadata, unique IDs/seeds/streams and assumption flags cannot prove genuine IID, conditional unbiasedness, fitting history or callback purity. Each finding names the evidence level, consequence and owner. Corrections require a new SHA and recheck of unchanged target/counterexample; never silently patch a native method or discard adverse outcomes.

Development, independent-validation and final-held-out are distinct access roles. This round used artificial values and public code/documents only. Separate worktrees/gitignore provide no OS security isolation. Technical custody requires human selection and later access testing. A5 provides requirements, not outsourced scientific approval.
