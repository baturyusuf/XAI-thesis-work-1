## 3. Certified coverage measures a pipeline, not ranking alone

Keep separate: (i) score-family attainable population frontier, (ii) pre-C finite-grid approximation, (iii) C risk/coverage rejection and abstention, (iv) independent T risk/coverage, (v) full resource cost. A delivered-certified-coverage metric combines all five and can be useful operationally without identifying superior quality ranking. On a valid safety event the respective reference/grid/selected coverage gaps can diagnose limits; on false-certification events selected unsafe coverage can exceed the safe frontier, so do not assume every empirical regret component is nonnegative.

If always-accept is already safe, full coverage is a valid saturated null: no selective need. For a separately justified prioritization question report prespecified same-coverage risk, expected-tie AURC/rank calibration and full costs with uncertainty, without turning descriptive prefixes into deployed certified thresholds. AURC is not a guarantee; partial tied blocks need explicit randomized acceptance/family correction. No primary metric/margin is frozen here.
