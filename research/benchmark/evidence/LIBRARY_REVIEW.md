## Applicability to the research estimands
The review context defines sufficient-subset evaluation through a declared completion law Q_(x,S) and selected model output; signed output difference and absolute distortion are distinct choices. H2 accepted functional risk is R(t)=E[L_exp | A_t=1], with coverage C(t)=P(A_t=1). It is not interchangeable with reference-attribution error, explanation variance, predictive confidence, or a robustness score. No package inspected establishes this project-specific loss or an accepted-risk guarantee.

### Quantus — useful metric components; image Infidelity is not the tabular oracle
The inspected Infidelity source declares image-only applicability; its default patch size is [4], perturbation sample count 10, baseline black, loss mse, and abs=False, normalise=False. It computes the selected model output before/after baseline-replaced patches and compares output deltas with attribution-weighted input deltas. The callable interface accepts model, x_batch, y_batch, optional a_batch, and softmax=False by default. Therefore output units (probability versus raw model score), selected target, patch/masker law, attribution scale, and optional absolute/normalization settings affect the estimand. Do not equate this patch test with subset sufficiency under Q_(x,S). The README explicitly cautions metric implementations may differ from original authors; an API exists, but its suitability here is not established.

### OpenXAI — benchmark metrics, not a declared completion-law evaluator
Pinned README documents Evaluator(model, metric=...).evaluate(**kwargs). It describes PGI/PGU as prediction probability gaps from perturbing important/unimportant features; RIS/RRS/ROS as relative stability measures; and FA/RA/SA-family agreement against ground-truth explanations, with logistic-regression coefficients given as an example. README-level claims only: exact masking/defaults, metric implementation details, output selection, and behavior with this study's Q or L_exp remain UNVERIFIED. Probability-gap, rank-agreement, and stability outputs answer different questions; none by itself is accepted functional risk.

### BEExAI — tabular pipeline with relevant metric names; semantics need source audit
Pinned README describes a tabular attribution benchmark and lists Infidelity, Comprehensiveness, Sufficiency, Faithfulness Correlation, Sensitivity, and complexity metrics. Its example invokes get_all_metrics(X_test.values, LABEL, trainer.model, exp) after pipeline training. This indicates a candidate source of comparison metrics, not proof that its Sufficiency equals the study's Q_(x,S)-expected output distortion or that its pipeline matches a frozen predictor. Exact formula, masker, defaults, target scale, normalization, and whether training/preprocessing can be bypassed are UNVERIFIED pending implementation inspection.

## Cross-cutting pitfalls
- Fix scalar/vector output, class/target selection, and units before comparing metrics. Probability gaps, logit/margin gaps, and output-vector distances differ. Scale-invariant correlations cannot detect magnitude calibration error; MSE and absolute losses change with scale.
- A baseline replacement, independent/marginal replacement, conditional completion, and causal intervention are not equivalent. State the masking/completion law and feature/group constraints. Use independent evaluation samples; same-law evaluation can be valid. Report deliberately different evaluation laws as cross-law stress, not universal truth.
- Attribution absolute-value transforms and normalization change explanation scale/sign semantics. Preserve signed values unless the estimand calls for magnitudes. Correlation can be undefined for constant vectors; do not silently impute a favorable score.
- Stability is diagnostic, not fidelity: a constant wrong explanation may be stable. Empirical perturbation sampling is not a supremum certificate or a finite-sample accepted-risk guarantee.

## Recommendation
First implement a small project-owned NumPy/SciPy oracle and bounded-risk evaluator, not a package-dependent score. On a controlled finite synthetic joint distribution, enumerate completions exactly under a declared Q_(x,S), fix the model output and loss scale, then separately assess signed/absolute subset distortion and H2 bounded loss. Include exact/known-sufficient, full, and size-matched random subsets, plus a deliberately misspecified completion law; use independent held-out draws for evaluation. Keep score fitting, calibration, and final evaluation separate; report coverage with conditional risk and do not treat AURC as a guarantee. Optional package adapters should follow explicit approval and source audit for formula, mask law, target, normalization, and total query cost.
