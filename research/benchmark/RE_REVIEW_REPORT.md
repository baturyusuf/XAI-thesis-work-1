Disposition: **minimal synthetic reference kernel is usable for its declared domain; no general scientific validation, novelty or final protocol approval.**

## 1. What is actually measured?
H1 computes original-label violation and declared-class absolute probability distortion under an explicit finite conditional law. These are distinct properties: a test preserves label with V=0 while distortion=3/20. Exhaustive finite-U certificate is separate again. Local minimality means single-deletion only; all-subset oracle searches the explicitly supplied group universe and returns all optima. Logical groups move one-hot coordinates together. No counterfactual/causal/personnel interpretation.

H2 loss measures E_M|p_c(Z)-h_E(Z)| or the explicitly changed clipped h_E, not universal explanation truth. Predictor/class/scale/order and surrogate are fixed before measurement. Native probability-valued analytic/sigmoid fixtures are covered. Wrong explanation types are rejected; attribution and subset methods are not silently reconstructed as surrogates. The H2 programme is not restricted to surrogates; other object-specific branches remain design/integration gates.

## 3. Exact reference observations, not algorithm superiority
Uniform XOR fixture: empty V=D=1/2, full V=D=0. An empirical eight-record fixture law gives empty V=1/4; wrong same-support masses give 1/5. Their own-law minimum is empty, but evaluated under true uniform law its V=1/2. Oracle search is exhaustive, so this fixture isolates law mismatch rather than needing a new search algorithm.

Identical f with diagonal U admits empty certificate; full binary U does not. This is support scope, not a certificate's failure under a within-U reweighting. For concentrated joint weights (1,9,9,81)/100, full S is single-deletion minimal at V<=1/4 but empty S is globally feasible with V=9/50. No paper implementation is declared broken.

Clipping counterexample: invalid raw probability rate=1/4 and raw loss=1/4, yet clipped loss=0 and gain=1/4. All diagnostics are returned, so apparent perfection cannot be interpreted as raw-surrogate fidelity. Projection onto [0,1] mechanically reduces absolute probability residual; improvement is not a better original explanation.

## 4. Independence, LTT and negative result
Existing LTT transform and bounded tests are reference implementations, not novel XAI or native package executions. Hoeffding and HB options, Bonferroni and prespecified fixed sequence, independent coverage bound and error allocation are explicit. The small five-observation population enumeration has an unsafe policy risk 2/3 at alpha1/2; each controller's exact false risk-rejection probability is 1/243, below 1/10, over 243 samples. This ONE finite case and null p-value enumerations do not prove a general theorem or all numerical configurations.

Synthetic pilot: 64 calibration and 64 independent-design evaluation units, score probes16 and loss probes32 per unit. Shared fixed E(x) generator for both scores; evaluation losses also integrated exactly. Six score/controller configurations had preallocated risk/coverage budgets summing to <=1/10. **All six returned NO_POLICY_CERTIFIED.** No valid deployment risk/coverage point was fabricated. Unit tests independently exercise an eligible all-zero-loss case, so the empty-set result is not a stub. This small/strict-budget failure is neither generic LTT inadequacy nor evidence for a new method. AURC remains descriptive; there is no matched-cost effectiveness claim.

Probe counts never enter calibration n. Reusing IDs, clusters, roles, draws, streams or seeds is rejected where detectable. Equal feature values from independent draws are allowed. Predictor/surrogate construction and preset grid do not use evaluator draws. Reference metadata still cannot authenticate actual sampling or fitting history.

## 5. Remaining risks / BLOCKED claims
- P1: IID, independent frozen order/fitting and conditional unbiasedness are design assumptions, not proven by unique IDs or Boolean flags. Missing/false declarations yield BLOCKED; falsely truthful declarations can fool this prototype. All real, temporal, subgroup or arbitrary-shift guarantees remain BLOCKED.
- P1: pure/stable callbacks and artifact bindings are assumed. Frozen metadata is not an immutable model function; future adapters should materialize finite outputs or audit determinism/hash immutable artifacts. No general runner/authenticated provenance shipped.
- P1: HB/log-CDF and coverage bounds use floating math; rational losses are exact, inference arithmetic is not formally verified interval arithmetic. Small hand/null tests are not all-n/near-endpoint numerical certification. Broad guarantee claims need additional independent numerical/theorem audit.
- P1: existing powerful learned-loss/Bayes score integrations and native baseline correctness are still untested. Toy direct probe/control scores do not settle their adequacy or any gap.
- P2: H1 currently requires x in positive joint support even when a partial conditioning event could be defined. This is an intentional conservative domain restriction; sparse empirical laws may BLOCK queries. Do not count such rejection as explanation failure.
- P2: strict exact probability-sum contract may reject ordinary floating outputs. No automatic normalization; a real adapter tolerance policy needs review. Finite support completeness is caller-supplied, not learned or proven here.
- P2: seeded tied ranks affect finite AURC/fixed coverage. Convention and deterministic tie endpoints are exposed; no cherry-picking seeds. Calibration policy uses fixed thresholds, not these test ranks.
- P2: query counts cover probe requests/unique sampled inputs and explicit evaluator work, not a complete hardware/runtime/memory profiler. Constant-confidence control has different cost; no same-cost superiority inferred. Rare tails, temporal robustness, attributions, real samplers, native verifiers and full logging/fallback orchestration are deferred.

## 6. Bias and falsification judgement
No new algorithm is present, so no parameter was optimized to favor it. Both controlled scores share f/E/law/units and the same error allocation; all no-certification outcomes are retained. Exact oracle is explicitly privileged. Clipped and native objects not pooled; law/support changes not called method errors. Synthetic mechanisms were chosen to exercise correctness/failure paths, not to support population-of-datasets superiority. No real data/final labels accessed.
