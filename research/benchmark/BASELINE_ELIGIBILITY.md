## Explicit comparator requirements (PROPOSED / BLOCKED)

- **H1 finite-domain:** exact subset enumeration on small finite domains is a required reference oracle, not evidence of a scalable native artifact. Include a standard verification-greedy comparator with its paper contract stated; if author code is unavailable, label the implementation theorem-/paper-faithful reference, never native. Final probability and single-deletion audit remain distinct; global minimum cardinality is claimed only where enumeration establishes it.
- **H2 primary target:** PROPOSED native local-surrogate bounded probability-residual loss E, evaluated with independent probes. Keep explanation-generator banks separate; every score is evaluated against the same E, fixed predictor/output target, sampler and total budget. This is a proposed measurement contract, not a selected winner or frozen protocol.
- **H2 strong score comparators:** Bayes local-error score, direct independent low-budget fidelity probe, and independently trained functional-loss predictor, each combined with LTT where assumptions hold. Training/calibration/evaluation splits and queries must be accounted independently; do not hide training or reuse costs. Bayes is eligible natively only if its posterior error actually targets that same E; otherwise mark target mismatch or separately named adaptation. These are required candidate comparators, not implementations claimed to exist here.
- LTT is risk control, not a score or explanation generator. Fix a policy/score family independently of calibration, use valid bounded-loss tests and FWER, and distinguish accepted-population conditional risk from per-instance/subgroup/shift claims.

## Critical blockers / contradictions

1. SST jointly trains and changes its predictor, so it cannot be silently ranked as an explanation of the fixed black box; use a separate intrinsic/training-cost arm or mark not comparable.
2. Missing official code for SIS, RDE, LmPAXp, abstraction-refinement, Selective Explanations, Bayes and conformal approximation is not proof no code exists and is not grounds for silently dropping strong rivals. Keep them blocked pending author artifact or separately identified faithful reference implementation.
3. SIS native threshold sufficiency and Q-distribution distortion are different targets; an adaptation must be named. More generally, calibrated f/g targets, rule precision, ordinal/global relevance, certificate properties, marginal CRC risk and LTT accepted-risk cannot be pooled as a single explanation score.
4. Adapters can change the object: attribution top-k, selector-only policies, mask discretization and fixed-target wrappers must be distinguished from native methods. Solver timeout/unknown is not certificate failure; LTT offers no automatic individual/subgroup/shift guarantee.
