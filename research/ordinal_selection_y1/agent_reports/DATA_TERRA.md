# Y1 ordinal dataset audit

The institutional TOC-UCO table lists 46 datasets, 22 OC=True entries and claims 30 randomized train-test partitions. All 22 catalog entries are recorded in the CSV; OC=True does not establish independent real ordinal tasks. Masks and individual source recipes were not inspected; extreme support, leakage and grouping remain unverified. Fewer than 14 eligible real datasets were verified, and four or five eligible real pilots were not established.

## Candidate handoff

- Wine Quality UCI 186: ordered sensory quality score 0-10, 11 continuous inputs; 4898 instances in UCI metadata, not a verified combined total. Red and white are one source family. Verify producer/batch groups, duplicates and extreme support. TOC red reports 1599 examples and five processed classes; recipe unverified. API https://archive.ics.uci.edu/api/dataset?id=186 ; prospective download https://archive.ics.uci.edu/static/public/186/data.csv .
- Student Performance UCI 320: G3 final grade 0-20, mixed tabular variables; UCI reports 649. Two schools and possibly overlapping students across subjects limit independence. G1 and G2 are correlated earlier grades; exclude for an early prediction task, check absences availability. Verify tails and group structure. API https://archive.ics.uci.edu/api/dataset?id=320 ; prospective download https://archive.ics.uci.edu/static/public/320/data.csv .
- Car Evaluation UCI 19: 1728 decision-model configurations, six categorical inputs, unacc < acc < good < vgood. Not real independent cars; only a rule-derived control. API https://archive.ics.uci.edu/api/dataset?id=19 ; prospective download https://archive.ics.uci.edu/static/public/19/data.csv .
- Nursery UCI 76: 12960 decision-model configurations, eight categorical inputs, application ranking. Not real independent applications; control only. UCI API target description repeats health-feature values; verify full class order and rare classes. API https://archive.ics.uci.edu/api/dataset?id=76 ; prospective download https://archive.ics.uci.edu/static/public/76/data.csv .

All four UCI landing pages explicitly state CC BY 4.0; cite source, link license and indicate changes as required. This license does not itself impose extra permission. Human verification is required for uncertain underlying TOC licenses and any conflicts; code license does not establish data rights. URLs for data are API metadata only and were not accessed.

Balance Scale left/balance/right is not a severity ordering; exclude. Dermatology diagnoses are nominal; exclude. Clinical datasets need expert interpretation and are deferred. Sensor datasets may share source families and repeated observations; check subject and session grouping. Airbnb requires host and temporal checks. For every candidate verify label definitions, duplicates, group and extreme-class counts before a split, fit preprocessing only on training data and avoid target-construction leakage. Thirty random splits are not thirty independent datasets.
