# Publication and immutable-source policy
Human authorized only research/xai-innovation commit/normal push; no main merge, force push, other worktree or new experiments. IMPLEMENTATION_WHITELIST.txt is the exact file set staged, never git add dot.

Only four pinned Google files plus our provenance note are redistributed as third-party code; Apache2 LICENSE/copyright unchanged, NOTICE root/SIS directory checked absent. No other reviewed source snapshots, binary packages, virtualenvs/cache/downloads/private/raw/hidden data included. Metadata URLs/SHAs remain available for excluded review snapshots. EXCLUSION_MANIFEST records local-retained omitted files; omission is not scientific deletion. Failed native conformance log and all12 H2 outcomes remain. Superseded draft/H1-attempt artifacts are explicitly historical, not current scientific evidence.

Machine absolute paths and hostnames in selected metadata/logs replaced by bracketed display tokens; raw originals remain ignored locally. REDACTION_MANIFEST binds original/published byte hashes. These are publication projections, not byte-identical raw execution logs. No predictor, target, probabilities, thresholds, source commit, loss, score, counters or scientific result changed. Literal native/benchmark source files are never redacted or patched. H2 initial result/config/unit records remain byte-identical.

.gitattributes -text protects pinned source/test and evidence bytes from automatic CRLF/LF conversion. Current SOURCE_SNAPSHOT_MANIFEST covers core scientific files excluding itself. Older review/solve all-tree manifests are historical, not republished as current digests. No self-referential hash claims. Source-object checks optional for archive/detached portability; baseline/source local hashes always checked. Validation writes to an explicit output directory, not frozen evidence by default.

An implementation commit freezes source/tests/results; a later documentation commit records its FULL SHA in AGENT5_INDEPENDENT_AUDIT_HANDOFF.md. Agent5 must not modify that implementation snapshot. Checks should run in a detached/isolated copy and write independent artifacts, without tuning frozen parameters. This package does not establish formal statistical guarantees, external preregistration custody, native paper replication or novelty.
