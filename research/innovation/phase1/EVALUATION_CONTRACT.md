# Evaluation contract v1 (before first LIME pilot output)
Native fitted LIME h is unbounded globally. The bounded LTT arm therefore explicitly targets clip(h,0,1), even if all observed h values are valid. Raw native losses, invalid rates and clipping gains are diagnostic, not silently replaced. The LIME perturbation law remains native Gaussian centered on x, weighted by the native kernel. Common evaluation law is four uniform offsets and is deliberately distinct.

The fitted Ridge estimator is captured through the documented model_regressor argument, with exactly default alpha1/intercept/random_state and feature selection none. An exact-conformance test compares to no hook. LIME feature weights live in scaler coordinates; the full surrogate retains scaler/intercept/order. Evaluation calls that same fitted estimator one point at a time (rowwise-native-estimator-eval-v1), preventing batch-size-dependent BLAS rounding from defining different h in score versus loss batches. This adapter does not refit or reorder coefficients. The original-instance prediction matches native local_pred. Predictor f returns original float probability vectors, validated within1e-12 without normalization. Selected-class losses use exact binary-float Fractions, not analytic-real tanh. No generic real-valued arithmetic or arbitrary-vector guarantee.

All new LTT policies share this explicit clipped explanation loss, one native bank, fixed target1 and five fixed thresholds. Four families x two budgets1/80 = total1/10. Calibration64 base observations, not64*16 perturbations. B32 only trains quality Ridge. T64 exact four-point losses are finite independent UNIT-loss measurements, NOT population integration over all LIME generation randomness. Numerical HB remains inherited non-interval arithmetic with1e-12 guard. Reproducible pseudorandom stream separation supports a conditional IID design, not a proof of physical random independence.
